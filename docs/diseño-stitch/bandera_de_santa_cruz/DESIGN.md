# Identidad visual: verde + dorado (bandera de Santa Cruz)

- Primario (marca): #0B6E4F, texto encima #FFFFFF. Se usa en botones, iconos activos, selección y el marcador del mapa selector.
- Acento: #E9A23B, texto encima #1D2622 (NUNCA texto blanco sobre el acento, no se lee). El acento se usa SOLO como fondo para destacar precios: pastillas de precio en el mapa y el badge de precio en las tarjetas de 'Mis lugares'. No usar el acento en botones genéricos ni iconos.
- Fondo de pantalla: #F6F2EA.
- Superficie (tarjetas): #FFFFFF.
- Texto principal: #1D2622.
- Texto secundario: #66706B.
- Nada de coral (#E8505B): paleta reemplazada por completo.
